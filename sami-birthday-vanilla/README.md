# Sami's Birthday Tulip Surprise 🌷

A plain HTML, CSS and JavaScript birthday website for Samiksha (Sami). No React, Vite, npm, build tools, or frameworks are required.

## Run it

1. Extract this ZIP.
2. Open the `sami-birthday-vanilla` folder.
3. Double-click `index.html` to open it in your browser.

For best results, you can also use VS Code with the Live Server extension and choose **Open with Live Server**.

## Files

- `index.html` – page content and sections
- `style.css` – all styling and animations
- `script.js` – balloon sequence, gift choices, music toggle and interactions
- `assets/garden/` – the included tulip garden images
- `assets/music/` – put your background music here

## Add background music

Put an MP3 file in `assets/music/` and name it:

`romantic.mp3`

The music starts after the visitor clicks the beginning button. Browsers generally require a user interaction before playing audio.

## Personalize the messages

Open `script.js` and edit the `wishes` array. It contains all 19 balloon messages. The Year 16 message is where the relationship story begins.

Open `index.html` to change the birthday text, date, or final message.

## Notes

- This version uses only HTML, CSS and vanilla JavaScript.
- There is no photo album, photo scanning, or couple-photo section.
- No installation or build command is needed.
